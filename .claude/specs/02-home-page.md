**Estado:** Implementado
**Depende de:** 01-mvp-pantallas-arcade-vault
**Fecha:** 2026-09-19

**Objetivo:** Implementar la landing (`/`) de Arcade Vault fiel a `references/templates/home-about/home.jsx` + `styles.css`, migrada a Next.js App Router con TypeScript, reemplazando el `redirect("/biblioteca")` actual de `app/page.tsx`.

## Alcance

**Incluye:**

- Ruta `/` con la landing (server component `app/page.tsx` + componente cliente `components/Home.tsx` para interactividad/reveal). Deja de redirigir a `/biblioteca`.
- Secciones del template, en orden:
  1. **Hero**: eyebrow "INSERTA UNA MONEDA_" (cursor parpadeante), titulo 3 lineas (EL ARCADE / CLÁSICO ESTÁ / DE VUELTA), subtitulo, CTAs "EXPLORAR JUEGOS" (`/biblioteca`) y "CREAR CUENTA" (`/login`), indicador "DESLIZA", 8 siluetas pixel flotantes (SVG decorativo, `aria-hidden`).
  2. **// 01 ¿POR QUÉ ARCADE VAULT?**: 4 feature cards (GAMEPAD, FREE, TROPHY, ROCKET) con iconos SVG pixel.
  3. **// 02 JUEGOS DISPONIBLES AHORA**: rail de 6 `MiniCard` (primeros 6 de `GAMES`) → `/juego/[id]`; boton "VER TODOS LOS JUEGOS" → `/biblioteca`.
  4. **Stats** (12+ juegos / miles de partidas / ranking global).
  5. **// 03 ACTIVIDAD EN VIVO**: ticker "Últimas puntuaciones" (7 filas mock) + "Top jugadores · hoy" (5 filas mock, boton "VER SALÓN" → `/salon`).
  6. **// 04 PRECIOS**: price card "Jugador Vault $0" + 3 FAQs; boton "EMPEZAR GRATIS" → `/login`.
  7. **CTA final** "¿LISTO PARA JUGAR?" → `/biblioteca`.
- Animacion `reveal` con `IntersectionObserver` (hook `useReveal`), con `transition-delay` escalonado en feature cards y stats.
- Navegacion: usar `next/link`/`useRouter` en lugar de `navigate({ name })` del template.
- Nav: agregar link **"Inicio"** (`/`) a desktop y drawer movil; logo apunta a `/`. Ajustar `isActive`: `biblioteca` deja de matchear `/` y `home` matchea solo `pathname === "/"`.
- Estilos: portar a `app/globals.css` los bloques `HOME PAGE` (`.home*`, `.section-*`, `.feature-*`, `.mini-*`, `.home-stats`/`.stat-*`, `.home-final`, `.reveal`), `ACTIVITY` (`.activity-*`, `.ac-*`, `.ticker`, `.tick-row`, `.top-*`, `.tp-*`, `.lb-link`, `.live-led`) y `PRICING` (`.pricing-*`, `.price-card`, `.pc-*`, `.faq-*`) de `styles.css`, sin tocar los estilos existentes.
- Metadata de la pagina (`title`/`description` en espanol) — corregir de paso el `description` "Generated by create next app" del layout.
- Responsive: mantener breakpoints del template (980/900/720/600/520px).
- Accesibilidad minima: CTAs como `<Link>`/`<button>` reales, siluetas `aria-hidden`, respetar `prefers-reduced-motion` (desactivar float/pulse/bounce/reveal).

**No incluye:**

- Pagina "Acerca de" (`about.jsx`) ni formulario de contacto: spec futura.
- Datos reales: actividad, top jugadores, stats y precios son mock estaticos.
- Cambios en Biblioteca, Detalle, Reproductor, Auth o Salon (salvo el ajuste de `isActive` en `Nav`).
- Tests automatizados (proyecto sin suite).

## Modelo de datos

Sin persistencia. Reusa `GAMES` de `lib/games.ts`. Datos mock estaticos tipados, en `lib/home.ts`:

```ts
export interface RecentScore { player: string; game: string; score: number; when: string; color: "cyan" | "magenta" | "yellow" | "green"; }
export interface TopPlayer { rank: number; player: string; score: number; }
export const RECENT_SCORES: RecentScore[]; // 7 filas, portadas de home.jsx
export const TOP_PLAYERS: TopPlayer[];     // 5 filas
export const FEATURES: { icon: "GAMEPAD" | "FREE" | "TROPHY" | "ROCKET"; title: string; desc: string; color: "cyan" | "yellow" | "magenta" | "green" }[];
```

Numeros formateados con `toLocaleString("es-ES")` (ojo hydration: valores fijos y locale explicito).

## Criterios de aceptacion

- [ ] `npm run build` sin errores de TypeScript ni ESLint.
- [ ] `/` renderiza la landing y ya no redirige a `/biblioteca`.
- [ ] Las 7 secciones aparecen en el orden del template con textos identicos (espanol).
- [ ] Todos los CTAs navegan: `/biblioteca`, `/login`, `/salon`, `/juego/[id]` (6 minicards).
- [ ] El rail muestra exactamente 6 juegos de `GAMES`.
- [ ] `reveal` anima al entrar en viewport; con `prefers-reduced-motion` el contenido es visible sin animacion.
- [ ] `Nav` muestra "Inicio" activo solo en `/`; "Biblioteca" ya no queda activo en `/`.
- [ ] Sin warnings de hydration en consola.
- [ ] Sin scroll horizontal en 360px de ancho.
- [ ] Estetica fiel al template (neon, pixel, siluetas flotantes, scanlines).

## Decisiones tomadas y descartadas

- **`/` como landing real** (no redirect): es lo que define el template; `/biblioteca` ya existe como catalogo.
- **Nav con "Inicio"**: el template lo incluye; evita que Biblioteca quede activo en `/`.
- **Portar CSS casi tal cual a `globals.css`**: mismo criterio que spec 01 (fidelidad visual sobre pureza Tailwind).
- **Datos de actividad/top/stats mock estaticos** en `lib/home.ts`: sin backend (fuera de alcance); estaticos evitan mismatch de hydration.
- **Sin pagina About** en esta spec: el template la trae, pero el pedido es solo home.
- **Se elimina la duplicacion `.fade-in`/`.slide-in`/`.spinner`** del final de `styles.css`: ya existen en `globals.css`, no se re-portan.
